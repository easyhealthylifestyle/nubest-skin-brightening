## Deploy with GitHub Pages

1. Create a public repository named `nubest-skin-brightening` under `easyhealthylifestyle`.
2. Upload the four files to the root of the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. The site will be live at `https://easyhealthylifestyle.github.io/nubest-skin-brightening/`.
